# DSA Patterns in Java

My data structures and algorithms practice in Java, organised by **pattern** instead of by problem number.

The goal is to understand *why* a technique works and *when* to reach for it, not to memorise solutions. Every problem 
has a working solution and a short notes file covering the slow approach, the key idea, the complexity, and the mistakes
I made along the way.
